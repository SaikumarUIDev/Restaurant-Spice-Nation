# 🍛 Spice Nation — Restaurant Website

A modern, responsive restaurant website designed for **Spice Nation**, an Indian restaurant based in ECIL, Kushaiguda, Secunderabad.

The website focuses on presenting the restaurant's brand, signature dishes, menu, dining experience, customer reviews, location, and contact information through a clean and premium user interface.

## 🌐 Live Demo

**[View Live Website](https://saikumaruidev.github.io/Restaurant-Spice-Nation/)**

---

## 📌 Project Overview

**Spice Nation** is a responsive restaurant website created with a modern Indian dining aesthetic.

The website includes:

* Hero section with restaurant branding
* Restaurant story and introduction
* Signature dishes section
* Interactive menu categories
* Biryani feature section
* Restaurant experience section
* Food and restaurant gallery
* Customer reviews
* Restaurant statistics
* Location and Google Maps integration
* Contact information
* Call-to-action sections
* Responsive navigation
* Mobile-friendly layout

## 🚀 Running the Project Locally

Clone the repository:

```bash
git clone https://github.com/SaikumarUIDev/Restaurant-Spice-Nation.git
```

Open the project:

```bash
cd Restaurant-Spice-Nation
```

Then open `index.html` in your browser.

For the best development experience, you can use **VS Code with the Live Server extension**.
